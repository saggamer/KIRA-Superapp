About the architecture +

The sparse architecture has an 11.804B logical parameter bound, including cloned, frozen expert layers. Around 29.6M adapter and router parameters were trainable per checkpoint. This is adapter training over a frozen base, rather than 11.804B distinct trained weights.

About the presentation pathway +

A dedicated presentation adapter proposes research, image, and slide actions. KIRA’s slide specialist writes and verifies the PPTX. A later image-tool continuation was selected for this branch on 11 October; a single source-backed topic produced a verified deck. That narrow trial is not a broad quality benchmark.

  2. Choose Orchestrator v1.5 in the chat model menu.
  3. Choose an effort level and describe the task, context, and boundaries.

Local inference requires a working Metal environment. Availability of a profile does not guarantee every workflow will complete.
